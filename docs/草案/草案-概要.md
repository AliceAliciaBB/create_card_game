# 草案-概要\_カードゲーム草案

## 概要

PvEの形式とする。
プレイヤー最大上限人数は6人とする。最低人数は一人とする。
共通のエネミー欄を用意し、そこにエネミーのカードを配置する。
未知山札からカードを引き、エネミー欄に配置する。
エネミー欄のエネミー上限枚数は6枚とする。(ハウスルールで可変)
未知山札からカードを引いてトレジャーを引いた場合はエネミーにトレジャーを装備(仮)させる。
エネミーのHPが0になった場合は、そのエネミーが装備しているすべてのトレジャーをエネミーをHPを0にしたプレイヤーが獲得する。獲得したトレジャーはプレイヤートレジャーゾーンに配置される。
エネミーも獲得するかどうか選択できる。エネミーを獲得した場合プレイヤーのトラッシュゾーンに配置される。エネミーを獲得しない場合は、エネミーは共通トラッシュに移動される。

## エネミー/キャラクターに記載される要素

- エネミーとキャラクターは同一カードである
- テーマ : 赤,青,緑,黄,紫,桃の6種類のテーマがある。テーマごとに一貫したデザインがされている。テーマごとに異なるスキルが設定される。
- HP :　体力。HPが0になった場合は、倒される。
- 記載枠1 :　スキル,パッシブスキル
- 記載枠2 :　スキル,パッシブスキル
- スキル例 :
    - 攻撃 : エネミーにダメージを与える。ダメージ量はスキルごとに異なる。->　指定コストを消費し、固定ダメージもしくはダイスを用いたランダムなダメージを与える。ダメージ量はスキルごとに異なる。
    - 回復 : HPを回復する。回復量はスキルごとに異なる。
    - パッシブスキル : 常時発動するスキル。パッシブスキルの効果はスキルごとに異なる。
- テーマ固有スキル : テーマ固有のスキル。テーマごとに異なるスキルが設定される。

## ゲームの流れ

### セットアップ

1.プレイヤーはそれぞれ未知山札からカードを6枚引く。
2.任意枚数のカードを一度共通トラッシュに配置する。共通トラッシュした枚数を未知山札から引く。
3.それはプレイヤー山札となる。なお、トレジャーがあってもこの時点では即時獲得にならない。(山札に入る) 
4.すべてプレイヤーがこの上記の手順を終えたら、共通トラッシュゾーンに配置されたカードをすべて未知山札に戻し、シャッフルする。
5.プレイヤー山札をシャッフルし、各プレイヤーは手札を3枚にする。トレジャーがあった場合はトレジャーエリアへトレジャーを移動する。
6.サモンエリアに一体以上のキャラを配置する。キャラのHPに合わせてダイスを配置する(HPのトークン)
7.任意の枚数コストエリアにキャラカードを表向きで配置する。
8.すべてのプレイヤーが上記の操作を終えた後親を決める(じゃんけんでもダイスでも良い)親から時計回りで進行する。
9.親は未知山札からカードを1枚引き、エネミー欄に配置する。エネミー欄の上限枚数は6枚とする。

### ゲームの進行
- 2人で記載するA:親,B:子とする。
- Aは自身のプレイヤー山札からカードを1枚引き、手札に加える。
- ターン中は以下のことが任意の順番で行える
    - トレジャーを使う
    - コストエリアにカードを表向きで配置する。(一ターンに1枚まで,コストエリアの最大6枚まで)
    - サモンエリアにキャラクターを右横向きで配置する(召喚酔い)。(一ターンに何枚でも可能,サモンエリアの最大6枚まで)
    - コストを払い、サモンエリアのキャラクターのスキルを使用する。(記載がない場合使用左後横向きにする)
    - 自身のサモンエリアにいて、召喚酔い(右向き)じゃないキャラクターのパッシブスキルを使用する。
- エネミーターン
    - エネミー一枚一枚に対して以下の処理を行う
    - 対象を決める 先にターンを終えたプレイヤーのサモンエリアのキャラクターを対象にダイスを用いて攻撃対象を選択する。
    - コストを決める ダイスを振り、出た目の数値が使用できるコストとなる。
    - 使用可能なコストの範囲でエネミーのスキルを使用する。使用したスキルのコストは消費される。
    - 複数利用可能なスキルがある場合は、使用するスキルをランダムで決定する。(HPが満タン状態で回復は使用しないなど)完全にランダムではない。
    - 次のエネミーのカードに処理が移る(同様の上記の処理)
- すべてのエネミーの処理が終わったら、次のプレイヤーのターンに移る。
- 2周以降は親がドロー前に、未知山札からエネミーエリアにカードを配置する。

- 指定時間繰り返す。(例: 30分)
- 終了時のエネミーターンが終了後、トレジャーの集計を行う。トレジャーの合計点が最も高いプレイヤーが勝利となる。

## 敗北条件
- サモンエリアのキャラクターがすべて倒された場合、そのプレイヤーは敗北となる。

## 用語

- ダイス : 6面ダイスを使用する。エネミーのスキル使用時や、攻撃対象の決定に使用する。
- トレジャー(仮) : 点が記載されたカード。これの合計点を競う。
- 未知山札(仮) : 共通エリアのカードの山札。エネミーやトレジャーなどが含まれる。
- エネミー欄(仮) : 共通エリアのカードの配置場所。エネミーやトレジャーなどが配置される。
- コストエリア(仮) : プレイヤーのカードの配置場所。コストが表示される。
- トラッシュゾーン(仮) : プレイヤーのカードの配置場所。エネミーが配置される。
- プレイヤートレジャーゾーン(仮) : プレイヤーのカードの配置場所。トレジャーが配置される。
- 共通トラッシュ(仮) : 共通エリアのカードの配置場所。エネミーやトレジャーなどが配置される。
