# 設計意思決定ログ

バランス調整・ルール変更・カード設計で「迷った」「変えた」「理由がある」ことをすべてここに残す。
後から「なぜこうなっているの?」にClaudeが答えられるようにするための記録。

## フォーマット

```
## YYYY-MM-DD: [対象] [変更内容の一言]
**決定内容**: 何をどう決めたか
**検討した候補**: 他に何を考えたか
**選んだ理由**: なぜこれにしたか
**懸念・未解決点**: まだ不安な点、今後検証したいこと
```

## 2026-10-09: ゲーム基本構造の初期草案決定

**決定内容**: PvE形式、最大6人、エネミー上限6枚、指定時間制でトレジャー点数を競う
**検討した候補**: PvP形式、デッキ構築型、ライフポイント制
**選んだ理由**: PvEにすることで協力/競合が両立できる。テーブルスペースと視認性から6枚上限に。
**懸念・未解決点**:
- 1人プレイ時のエネミー6枚が多すぎないか未検証
- 指定時間が何分が適切か未定
- トレジャーの点数バランス未定

## 2026-10-09: 緑カード初期5枚(暫定)

**決定内容**: 翠の守護者・癒しの苔精・大樹の加護・盾の乙女・根の番人を暫定登録
**設計変更**:
- 翠の守護者: タント(攻撃対象を強制) → 全体ダメージ-1パッシブに変更。タントより自然でルールも簡潔
- 盾の乙女: シールド付与 → ダメージ肩代わりに変更。新概念「シールド」を追加せずに済む
**ルール確定**: HPはダイスで管理するためキャラクターのHP上限は6。翠の守護者のHP8→6に修正
**懸念・未解決点**:
- 大樹の加護の複数枚重複ルールが未定(2枚並べると+2になるか)
- 癒しの苔精はHP2なので守護者がいないと即倒される運用が前提になる

## 2026-10-09: 黄カード初期5枚(暫定)

**決定内容**: 黄金の博徒・幸運の道化・呪縛の術師・二重賭け師・大逆転師を暫定登録
**黄金の博徒の設計変更**:
- 当初: 出目1=失敗・自傷、2以上=エネミーのみダメージ
- 変更後: 出目=エネミーダメージ兼自傷ダメージ(常に両方発生)
- 理由: 常に自傷があることで「出目を下げる戦略」「回復役の需要」が生まれ、他カードとの連携に意味が出る
**呪縛の術師の変更**:
- 当初: エネミーのダイス出目-1のみ
- 変更後: 自分のターン中、自分とエネミー両方の出目-1(他プレイヤーターン中は無効)
- 理由: 博徒の自傷を意図的に減らす手段として機能させるため
**懸念・未解決点**:
- 幸運の道化(+1)と呪縛の術師(-1)が同時にいるとキャンセルし合う→意味がなくなる
- 呪縛の術師がエネミーも-1するのでデメリットなしに強い可能性
- 二重賭け師と博徒の使い分けが明確かどうか(自傷条件が違うが役割が近い)

## 2026-10-09: 各テーマ色の設計方針(暫定)

**決定内容**:
- 赤: 速攻系。召喚酔いなしキャラが多い。代わりにダメージが低い
- 黄: ギャンブル系。ダイスの出目でダメージや効果が変わる
- 緑: トークン系。攻撃できないが仲間バフのトークン + 守り役キャラ
- 白: 無色。キャラではなくコスト代替専用。どの色コストの代わりにも使える
- 青/紫/桃: 未定
**検討した候補**: (まだ検討段階のため省略)
**選んだ理由**:
- 赤の召喚酔いなし: 速攻の恩恵を出しつつ、ダメージ低でリターンとトレードオフ
- 黄のダイス依存: ゲーム全体にダイスが絡む世界観と一致。ハイリスク・ハイリターン枠
- 緑のトークン: 攻撃役との分業でパーティー組み合わせに奥行きを出す
- 白の無色: デッキ構築の自由度を上げるが、固有テーマなしなのでパワーを抑えやすい
**懸念・未解決点**:
- 赤のダメージ低はどの程度低くすべきか (他色比較がないと決められない)
- 緑のトークンが守るだけだと使われない可能性 → 何かしら攻撃貢献手段が必要か
- 白のコスト代替がどれだけ強いかはコスト設計次第。過剰に強くなる危険あり
- 青: 海/捕食系に決定。味方を捕食してHP回復やパワーアップを得る食物連鎖テーマ。捕食効果の詳細はカードごとのスキル記載に委ねる(全体ルール化しない)
- 桃: 寄生/装備系に決定。他カードに装着しコストを桃コストに上書き、バフ/デバフを付与する独自メカニクス。装着先は味方・エネミー両方可
- 紫: 宇宙系(ブラックホール・隕石)に決定。自爆特攻・死亡時大ダメージが軸になる想定。緑「死亡時回復」の攻撃版として差別化できる

## 2026-10-09: 赤カード初期5枚(暫定)

**決定内容**: 疾風の剣士・炎の矢師・紅蓮の猛者・火炎舞い・先駆けの旗手を暫定登録
**各カードの役割**:
- 疾風の剣士: 主力速攻。赤の基本形
- 炎の矢師: HP2の超低耐久。召喚即パッシブで仲間の召喚酔い解除
- 紅蓮の猛者: 赤の例外・重量型。召喚酔いあり・高ダメージで速攻テーマの対比
- 火炎舞い: 1×3の分散ヒット。複数エネミー削り特化
- 先駆けの旗手: 攻撃0の純サポート。召喚コスト-1パッシブ持ち
**懸念・未解決点**:
- 炎の矢師・先駆けの旗手の「召喚酔い解除」効果が重複して強すぎる可能性
- 先駆けの旗手の召喚コスト-1パッシブはコスト設計次第で壊れ性能になりうる
- 紅蓮の猛者が赤に必要かどうか未確定(コンセプト対比として入れたが浮いている可能性)
- コスト「赤1」がコストエリアの赤カード枚数で支払うイメージで合っているか未確認

## 2026-10-09: HPコストを新ルールとして追加

**決定内容**: スキルのコストとして自分のHPを消費する「HPコスト」を新設。カードに「コストHP〇」と記載する
**選んだ理由**: シャチの設計で自然に発生した。青の捕食テーマと相性が良い(自分を削って強力なスキルを使う)
**懸念・未解決点**:
- カラーコストとの併用可否が未定(コストHP3のみ、または青2+HP1のような混合コストも可能か)
- HPコストで自分のHPが0になった場合は自滅扱いになるか未定

## 2026-10-09: 召喚コストなし(コストはスキル使用時のみ)

**決定内容**: キャラの召喚(サモンエリアへの配置)にコストは不要。コストはスキル使用時にのみ消費する
**検討した候補**: HPを召喚コストにする、召喚コストを個別ステータスとして持つ
**選んだ理由**: ゲームの核はスキルコスト管理とエネミー処理の優先順位。召喚にもコストをかけるとリソース管理が複雑になりすぎる
**派生変更**: 先駆けの旗手のパッシブ「召喚コスト-1」→「スキルコストを-1(1ターン1回まで)」に差し替え

## 2026-10-09: エネミーターンのコスト決定をダイスで行う設計

**決定内容**: エネミーターンはダイスを振り、出た目がそのターンの使用可能コスト
**検討した候補**: 固定コスト毎ターン、HPに連動したコスト
**選んだ理由**: ランダム性を入れることで毎回異なる展開になる。ルールをシンプルに保てる。
**懸念・未解決点**: コスト1しか出なかった場合にエネミーが弱すぎる。最低コスト保証が必要か要検討。
