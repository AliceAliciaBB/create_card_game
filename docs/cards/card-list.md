## テーマ一覧 (色の設計方針)

| テーマ色 | コンセプト | 特徴 | ステータス |
|---------|-----------|------|-----------|
| 赤 | 速攻系 | 召喚酔いなしキャラが多い。代わりにダメージが低い | 暫定決定 |
| 黄 | ギャンブル系 | ダイスの出目でダメージや効果が変わる | 暫定決定 |
| 緑 | トークン系 | 攻撃できないが仲間にバフを与えるトークン + 守り役キャラが含まれる | 暫定決定 |
| 青 | 未定 | - | 未定 |
| 紫 | 未定 | - | 未定 |
| 桃 | 未定 | - | 未定 |
| 白 | 無色(コスト代替) | どの色コストの代わりにも使える汎用コスト。キャラとしての固有テーマはなし | 暫定決定 |

## エネミー/キャラクターカード

### 赤テーマ (速攻系)

#### 疾風の剣士 ※暫定
- テーマ: 赤
- HP: 4
- 召喚酔い: なし
- スキル1: 斬撃 (コスト赤1) → 2ダメージ
- スキル2: 連斬 (コスト赤2) → 1ダメージ×2回(別エネミーに分散可)
- バランスメモ: 赤の基本形。安いコストで動け、連斬で複数エネミーを削れる速攻役

#### 炎の矢師 ※暫定
- テーマ: 赤
- HP: 2
- 召喚酔い: なし
- スキル1: 火矢 (コスト赤1) → 1ダメージ(エネミー任意選択)
- パッシブ: 場に出た瞬間、味方キャラ1体の召喚酔いを解除する
- バランスメモ: HP極低。召喚即パッシブで他キャラの速攻を補助するサポート寄り

#### 紅蓮の猛者 ※暫定
- テーマ: 赤
- HP: 6
- 召喚酔い: あり (赤では珍しい重量型)
- スキル1: 烈火撃 (コスト赤3) → 5ダメージ
- スキル2: 炎陣 (コスト赤2) → 3ダメージ + 次の自分のターンまで対象エネミーのコスト-1
- バランスメモ: 赤の例外枠。召喚酔いあり・コスト重い代わりにダメージ赤最高。速攻テーマの対比として存在

#### 火炎舞い ※暫定
- テーマ: 赤
- HP: 3
- 召喚酔い: なし
- スキル1: 舞い斬り (コスト赤1) → 1ダメージ×3回(同エネミー・別エネミー自由)
- バランスメモ: 総ダメージ3と低いが複数エネミーのHP削りに特化。緑バフとの相性要検証

#### 先駆けの旗手 ※暫定
- テーマ: 赤
- HP: 3
- 召喚酔い: なし
- スキル1: 鼓舞 (コスト赤1) → 味方キャラ1体の召喚酔いを解除する
- パッシブ: サモンエリアにいる限り、味方キャラの召喚コストを-1する
- バランスメモ: 攻撃0の純サポート。他色キャラを速攻させる橋渡し役。強すぎる可能性あり要注意
