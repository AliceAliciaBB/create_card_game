## カードの共通フォーマット

```
## [カード名]
- テーマ: 赤/青/緑/黄/紫/桃
- HP: [数値]
- スキル1: [スキル名](コスト[数値]) → [効果説明]
- スキル2: [スキル名](コスト[数値]) → [効果説明]  ※なければ省略
- パッシブ: [効果説明]  ※なければ省略
- バランスメモ: [調整経緯など]
```

## テーマ一覧 (色の設計方針)

| テーマ色 | コンセプト | 特徴 | ステータス |
|---------|-----------|------|-----------|
| 赤 | 速攻系 | 召喚酔いなしキャラが多い。代わりにダメージが低い | 暫定決定 |
| 黄 | ギャンブル系 | ダイスの出目でダメージや効果が変わる | 暫定決定 |
| 緑 | トークン系 | 攻撃できないが仲間にバフを与えるトークン + 守り役キャラが含まれる | 暫定決定 |
| 青 | 未定 | - | 未定 |
| 紫 | 未定 | - | 未定 |
| 桃 | 未定 | - | 未定 |
| 白 | 無色(コスト代替) | どの色コストの代わりにも使える汎用コスト。キャラとしての固有テーマはなし | 暫定決定 |
