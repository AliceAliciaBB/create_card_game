## テーマ一覧 (色の設計方針)

| テーマ色 | コンセプト       | 特徴                                                                                                                                            | ステータス |
| -------- | ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| 赤       | 速攻系           | 召喚酔いなしキャラが多い。代わりにダメージが低い                                                                                                | 暫定決定   |
| 黄       | ギャンブル系     | ダイスの出目でダメージや効果が変わる                                                                                                            | 暫定決定   |
| 緑       | トークン系       | 攻撃できないが仲間にバフを与えるトークン + 守り役キャラが含まれる                                                                               | 暫定決定   |
| 青       | 海/捕食系        | 味方キャラを捕食することで回復やパワーアップを得る食物連鎖テーマ。捕食効果の詳細(回復先・食べられた後の処理)はカードごとにスキルに記載          | 暫定決定   |
| 紫       | 宇宙系           | ブラックホール(引き寄せ・吸収)や隕石(自爆特攻・死亡時大ダメージ)が含まれる想定                                                                  | 暫定決定   |
| 桃       | 寄生/装備系      | 他のカード(味方・エネミー両方可)に装着し、コストを桃コストに上書きする代わりにバフ/デバフを与える。見た目は可愛い寄生生物・トッピングのイメージ | 暫定決定   |
| 白       | 無色(コスト代替) | どの色コストの代わりにも使える汎用コスト。キャラとしての固有テーマはなし                                                                        | 暫定決定   |

## エネミー/キャラクターカード

### 赤テーマ (速攻系)

#### 疾風の剣士 ※暫定

- テーマ: 赤
- HP: 4
- 召喚酔い: なし
- スキル1: 斬撃 (コスト赤1) → 相手1体に2ダメージ
- スキル2: 連斬 (コスト赤2) → 相手1体に1ダメージ×2回(同じ相手でも別の相手でも可)
- バランスメモ: 赤の基本形。安いコストで動け、連斬で複数エネミーを削れる速攻役

#### 炎の矢師 ※暫定

- テーマ: 赤
- HP: 2
- 召喚酔い: なし
- スキル1: 火矢 (コスト赤1) → 相手1体に1ダメージ
- パッシブ: 場に出た瞬間、他の味方1体の召喚酔いを解除する
- バランスメモ: HP極低。召喚即パッシブで他キャラの速攻を補助するサポート寄り

#### 紅蓮の猛者 ※暫定

- テーマ: 赤
- HP: 6
- 召喚酔い: あり (赤では珍しい重量型)
- スキル1: 烈火撃 (コスト赤3) → 相手1体に5ダメージ
- スキル2: 炎陣 (コスト赤2) → 相手1体に3ダメージ + 次の自分のターンまでその相手のコスト-1
- バランスメモ: 赤の例外枠。召喚酔いあり・コスト重い代わりにダメージ赤最高。速攻テーマの対比として存在

#### 火炎舞い ※暫定

- テーマ: 赤
- HP: 3
- 召喚酔い: なし
- スキル1: 舞い斬り (コスト赤1) → 相手に1ダメージ×3回(同じ相手でも別の相手でも自由に分散可)
- バランスメモ: 総ダメージ3と低いが複数エネミーのHP削りに特化。緑バフとの相性要検証

#### 先駆けの旗手 ※暫定

- テーマ: 赤
- HP: 3
- 召喚酔い: なし
- スキル1: 鼓舞 (コスト赤1) → 他の味方1体の召喚酔いを解除する
- パッシブ: サモンエリアにいる限り、他の味方1体のスキルコストを-1する(1ターンに1回まで)
- バランスメモ: 攻撃0の純サポート。他色キャラのスキルを安く使わせる橋渡し役。強すぎる可能性あり要注意

### 黄テーマ (ギャンブル系)

#### 黄金の博徒 ※暫定

- テーマ: 黄
- HP: 6
- 召喚酔い: あり
- スキル1: 大賭け (コスト黄3) → ダイスを振る。相手1体に出目の数値のダメージを与え、同じ数値だけ自分もダメージを受ける(出目1=相手1/自傷1、出目6=相手6/自傷6)
- バランスメモ: 常に攻撃と自傷が同時発生。出目を下げる戦略が延命手段になる。HP6でも出目6連続は危険

#### 幸運の道化 ※暫定

- テーマ: 黄
- HP: 3
- 召喚酔い: なし
- パッシブ: サモンエリアにいる限り、味方全体のダイスの出目に+1する(最大6)
- バランスメモ: 博徒と組むと自傷も+1される諸刃。B+C同時存在でキャンセルし合う可能性あり。要検証

#### 呪縛の術師 ※暫定

- テーマ: 黄
- HP: 3
- 召喚酔い: なし
- パッシブ: 自分のターン中のみ、自分とエネミーのダイスの出目を-1する(最小1)。他プレイヤーのターン中は無効
- バランスメモ: 博徒の自傷を意図的に減らす戦略カード。エネミーも同時に弱体化するのでデメリットなし。強すぎる可能性あり

#### 二重賭け師 ※暫定

- テーマ: 黄
- HP: 3
- 召喚酔い: あり
- スキル1: 二連賭け (コスト黄2) → ダイスを2回振り、それぞれ別の相手1体に出目ダメージを与える。1が出た回数×2だけ自分にダメージ
- バランスメモ: 博徒の複数エネミー版。自傷条件が異なる(1のみ自傷)ため博徒より安定寄り

#### 大逆転師 ※暫定

- テーマ: 黄
- HP: 4
- 召喚酔い: あり
- スキル1: 大逆転 (コスト黄2) → ダイスを振る。1〜3: 味方全体のHPを出目分回復。4〜6: 相手1体に出目×2ダメージ
- バランスメモ: 低出目→回復、高出目→大火力の二面性。回復役としての需要も生まれ黄の幅を広げる

### 緑テーマ (トークン系)

#### 翠の守護者 ※暫定

- テーマ: 緑
- HP: 6
- 召喚酔い: あり
- スキル: なし(攻撃不可)
- パッシブ: サモンエリアにいる限り、味方全体が相手から受けるダメージを-1する(最小0)
- バランスメモ: ダメージ軽減アーラ役。HPはダイス管理のため上限6に修正。攻撃0なので最大値で妥当

#### 癒しの苔精 ※暫定

- テーマ: 緑
- HP: 2
- 召喚酔い: なし
- スキル: なし(攻撃不可)
- パッシブ: 自分のターン開始時、味方1体のHPを1回復する
- バランスメモ: 黄金の博徒の自傷を毎ターン補填できる。HP2と脆いので守護者との組み合わせが前提になりやすい

#### 大樹の加護 ※暫定

- テーマ: 緑
- HP: 2
- 召喚酔い: なし
- スキル: なし(攻撃不可)
- パッシブ: サモンエリアにいる限り、味方全体のスキルダメージ+1
- バランスメモ: 赤の低ダメージを底上げする。複数枚の重複ルールは未定

#### 盾の乙女 ※暫定

- テーマ: 緑
- HP: 4
- 召喚酔い: なし
- スキル1: 守護の盾 (コスト緑1) → 味方1体を指定。次にその味方が受けるダメージを代わりにこのキャラが受ける(1回)
- バランスメモ: 能動的に1回だけ仲間を守る。守護者(常時-1)との役割が異なる。HP4なので大ダメージの肩代わりは危険

#### 根の番人 ※暫定

- テーマ: 緑
- HP: 5
- 召喚酔い: あり
- スキル: なし(攻撃不可)
- パッシブ: このキャラが倒された時、味方全体のHPを3回復する(自分除く)
- バランスメモ: 生存中は何もしないが、倒されることで貢献する。長期戦で真価を発揮
